# 푸른하늘 지킴이 · 미세먼지 계절관리제 대작전

12월부터 3월까지 넉 달 동안 마을을 걸어 다니며 **미세먼지 계절관리제, 비상저감조치, 시민 행동요령**을 배우는 3D 웹 게임입니다. 임무를 해낼수록 마을의 초미세먼지 농도가 내려가고(33 → 목표 19㎍/㎥) 뿌연 하늘이 맑아집니다.

- `index.html` 하나와 `vendor/three/`로 동작하는 정적 사이트입니다. 빌드 과정이 없습니다.
- [푸른하늘 업무체험관](https://github.com/todaynit1-sys/mamo-ex2)과 같은 방식(three.js 0.160.0, 단일 파일, 푸르미·맑음이 마스코트, 같은 화면 색과 글씨)으로 만들었습니다.
- three.js는 `vendor/`에 들어 있어 외부 CDN이 막힌 기관망에서도 열립니다. `index.html`을 파일로 바로 열면(file://) 그때만 인터넷에서 같은 버전을 받습니다.

## 네 가지 임무

| 달 | 장소 | 내용 | 배우는 것 |
|---|---|---|---|
| 12월 | 운행제한 단속 초소 | 차 10대의 요일·시각·등급·표지를 보고 단속/통과 고르기 (한 대에 12초) | 5등급 차량 운행제한: 평일 오전 6시~오후 9시, 과태료 하루 10만 원, 단속 제외 차량 |
| 1월 | 미세먼지 종합상황실 | 예보 자료로 발령 판단 5문제 → 1단계 조치 고르기 → 위기경보 4단계 순서 | 비상저감조치 발령 기준 세 가지, 단계별 조치, 관심·주의·경계·심각 |
| 2월 | 우리 집 | 고농도 날 아침부터 저녁까지 일곱 번의 선택 | 고농도 미세먼지 7가지 대응요령 |
| 3월 | 마을 곳곳 | 배출원 다섯 곳(밭두렁 소각·공회전 버스·공사장 날림먼지·도로 먼지·문 열고 난방) 찾아가 해결 | 봄철 총력대응, 생활 속 저감 |

- 임무마다 별을 1~3개 받습니다. 임무 하나에 2.5, 별 하나에 0.4㎍/㎥씩 내려가서, 별 9개 이상이면 목표 19㎍/㎥에 닿습니다. 끝난 임무는 그 장소에서 다시 도전해 별을 올릴 수 있습니다.
- 1~2월에는 "오늘 82㎍/㎥ · 매우 나쁨" 고농도 상황이 되어 하늘이 더 뿌옇게 바뀝니다.
- 다 마치면 성적표와 **푸른하늘 지킴이 인증서**(1080×1350 그림)가 나오고, 저장하거나 공유할 수 있습니다. 그림은 그 기기 안에서만 만들어집니다.
- 오른쪽 위 **📒 수첩**에 계절관리제, 5등급 운행제한, 비상저감조치(발령 기준·위기경보·단계별 조치), 시민 행동요령이 정리되어 있습니다.

## 조작

- PC: `W` `A` `S` `D`·방향키로 이동(`Shift` 달리기), `E`·`Space`로 말 걸기, `G` 바로 가기, `N` 수첩
- 모바일: 왼쪽 아래 조이스틱으로 이동, 오른쪽 아래 버튼으로 말 걸기
- 땅이나 사람을 누르면 그리로 걸어갑니다. **📍 바로 가기**를 누르면 지금 할 일이 있는 곳까지 알아서 걸어갑니다.
- 진행 기록은 그 브라우저에만 저장됩니다(`localStorage`의 `pm-season-v1`). 시작 화면의 "기록 지우고 처음부터"로 지웁니다.

## 내용 출처와 고칠 곳

- 기후에너지환경부 보도자료 「고농도 초미세먼지 재난대응 모의훈련 실시」(2025.11.18.): 위기경보 기준, 단계별 조치사항
- 국무조정실 보도자료 「제17차 미세먼지특별대책위원회」(2025.11.25.): 제7차 계절관리제 시행계획
- 기후에너지환경부 보도자료 「범부처 봄철 초미세먼지 저감 총력 대응」(2026.2.24.): 봄철 총력대응, 고농도 미세먼지 7가지 대응요령
- 수원시 누리집 미세먼지 안내(비상저감조치·계절관리제·예경보제): 5등급 차량 운행제한 시간과 과태료, 시민 실천 네 가지, 주의보·경보 기준

수치는 **제7차 계절관리제(’25.12~’26.3) 기준**입니다. 다음 차수 계획이 나오면 아래를 고치면 됩니다.

| 위치 (`index.html`) | 내용 |
|---|---|
| `F` (스크립트 맨 위) | 시작 농도 33, 목표 19, 고농도 날 예시 농도 82, 차수 표기 |
| `ORG` (스크립트 맨 위) | 인증서 아래에 넣을 기관 이름. 비워 두면 넣지 않음 |
| `NOTES` | 지킴이 수첩 글 (석탄발전 기수, 사업장 수 등) |
| `carItems`·`playM2`·`playM3`·`SRC` | 임무별 문제와 설명 |

게임 속 농도 변화와 82㎍/㎥ 상황은 체험용 예시입니다. 5등급 차량 운행제한의 세부 기준은 지역마다 다를 수 있습니다.

## 실행

정적 파일 서버로 이 폴더를 열면 됩니다. 예:

```bash
npx serve .
```

주소 끝에 `#debug`를 붙이면 `window.__g`(상태 보기, `__g.step(n)`으로 프레임 진행)로 시험할 수 있습니다.
