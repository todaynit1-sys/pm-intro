# 하늘 수비대 · 미세먼지 계절관리제 대작전

구름보드를 타고 뿌연 도시를 되찾는 게임. 미세먼지 계절관리제·비상저감조치·시민 행동요령을 다섯 가지 작전으로 배웁니다.
그림은 모두 코드로 그린 벡터 모션그래픽(캔버스), 글자는 그 위에 얹은 HTML. 그림 파일·게임 엔진·빌드 도구 없음.

- 첫 화면: https://pm-intro.vercel.app (`index.html`)
- 오락실(옛날 오락기 슈팅): `/arcade/` — 앱 안 '오락실'에서 들어감
- 예전 3D 마을판: `/town/` (그대로 보관)

## 구성

| 곳 | 배우는 것 | 놀이 |
|---|---|---|
| 먼지 연구소 | 미세먼지란? 크기, 예보 등급 | 현미경 확대 → 거름망 → 등급 빨리 맞히기 |
| 5등급 검문소 | 5등급 차량 운행제한 (평일 06~21시, 제외 차량) | 지나가는 차 가운데 단속 대상만 누르기 |
| 비상 상황실 | 비상저감조치 발령 기준과 조치 | 오늘·내일 농도 보고 발령 판단, 할 일 고르기 |
| 굴뚝 공단 | 배출원별 계절관리제 대책 | 먼지몬이 붙은 곳에 알맞은 대책 고르기 |
| 우리 동네 | 고농도 날 7가지 대응요령 | 5초짜리 행동 일곱 가지 릴레이 |
| 오락실 | (복습) | `/arcade/` 레트로 슈팅 |

그 밖에: 대원 꾸미기(타입·머리·얼굴·옷·장비·보드), 하늘멍(낮·노을·밤), 수비대 수첩, 인증서 저장.
작전을 마치고 별을 모을수록 도시 농도가 33 → 19㎍/㎥로 내려가고 하늘이 맑아집니다.

## 고치는 법

`index.html` 은 `src/` 의 조각을 이어 붙인 결과물입니다. **`src/` 를 고친 뒤 `node src/build.mjs`** 를 실행하세요.

| 파일 | 내용 |
|---|---|
| `src/1_head.html` | 머리말, 스타일, 화면 뼈대 |
| `src/2_core.js` | 수치(`F`), 저장, 소리, 화면 틀, 트윈, 반짝이, 화면 넘김·큰 글자 |
| `src/3_art.js` | 그리기: 하늘, 도시, 작전지 건물, 대원, 먼지몬, 자동차 |
| `src/4_hub.js` | 제목, 꾸미기, 본부, 하늘멍, 수첩, 설정, 인증서 |
| `src/5_play.js` | 작전 공통 틀 (들어가기·결과) |
| `src/6_games.js` | 작전 다섯 가지 (문제·보기·설명 글도 여기) |
| `src/9_boot.js` | 시작, 디버그(`#debug` → `__g`) |

- 수치는 `src/2_core.js` 의 `F` (제7차 계절관리제 ’25.12~’26.3 기준: 시작 33, 현재 20, 목표 19).
- 인증서에 기관 이름을 넣으려면 `ORG` 에 적습니다 (비워 두면 넣지 않음).
- 수첩 글(`NOTES`)은 `arcade/index.html` 에 있고, 빌드할 때 그대로 가져옵니다.
- 저장은 기기 안(localStorage `sky-hq-v1`, 오락실은 `sky-guard-v1`)에만 됩니다.
