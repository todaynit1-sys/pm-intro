# 푸른하늘 지킴이 · 미세먼지 계절관리제 대작전

직접 걸어 다니며 미세먼지 계절관리제·비상저감조치·시민 행동요령을 알아 가는 3D 마을 게임.
빌드 도구 없이 정적 파일만으로 돌아갑니다 (three.js 는 `vendor/` 에 들어 있음).

| 주소 | 내용 | 파일 |
|---|---|---|
| https://pm-intro.vercel.app | **3D 마을 (첫 화면)** — 걸어 다니며 다섯 가지 체험 | `index.html`, `skin.css` |
| `/hq/` | 하늘 수비대 — 2D 미니게임 다섯 가지 | `hq/index.html` (← `src/` 를 빌드) |
| `/arcade/` | 하늘 수비대 아케이드 — 옛날 오락기 슈팅 | `arcade/index.html` |

마을 안의 **바로 가기** 목록에서 2D 미니게임과 오락기 슈팅으로 갈 수 있습니다.

## 3D 마을 (`index.html`)

- **캐릭터**: 하늘 수비대원(큰 머리, 목도리, 고글, 잉크 테두리). 꾸미기는 종류·피부·머리·눈·옷·목도리·장비. 코드에서는 `makePerson`, `mountCreator`, 기본 모습은 `AV0`.
- **길동무**: 구름 '뭉게'와 물방울 '방울이'가 따라다닙니다. 말을 걸면 다음 할 일을 알려 주고 데려다줍니다 (`makeMascot`, `nextTask`).
- **체험 다섯 가지**: 미세먼지 연구소 · 단속 카메라(5등급 운행제한) · 상황실(비상저감조치) · 심부름 대작전(고농도 날 행동) · 배출원 줄이기.
- **설명 방식**: 쉬운 말이 기본이고, 숫자와 기준은 대화의 **자세히 알려 줘** 와 수첩에 있습니다 (`intro(who, 쉬운말, 자세히, 단추, 시작)`).
- **꾸미기**: 먼저 남자·여자를 고르고(머리·옷 목록이 성별마다 다름: `HAIRS_M/F`, `TOPS_M/F`, `fitBody`), 머리 11·눈 6·입 5·옷 5·머리 장비 13·등 4·손 4가지와 색. 일부는 체험·별·구슬·먼지몬으로 열립니다 (`LOCKS`, `checkUnlocks`).
- **2D 게임을 마을 안에서**: 연구소·상황실은 `/hq/` 의 2D 미니게임을 화면 위에 겹쳐 열고, 끝나면 결과(별)를 받아 체험 완료로 처리합니다 (`playHq`, `openFrame`). 우리 집에서는 심부름(3D)과 행동 릴레이(2D) 가운데 고르고, 오락기에서는 먼지몬 막기(30초 동안 몰려오는 먼지몬 누르기, `startDust`)가 기본이고 5등급 스캐너·굴뚝 공단·슈팅 오락도 고릅니다.
- **인증샷 포토존** (광장 남쪽): 체험을 `CERT_NEED`(기본 3)가지 마치면 '미션 완료' 도장과 마친 체험이 들어간 인증샷을 찍어 저장·공유합니다. 그 전에는 기념사진. 사진은 기기 안에서만 만들어집니다.
- 그 밖에: 하늘멍·마을멍·물멍, 하늘 구슬, 먼지몬, 사진, 성적표·인증서.
- 화면(단추·판·글꼴) 모양은 `skin.css` 에서 바꿉니다.
- 수치는 `F`, 인증서에 넣을 기관 이름은 `ORG` (비워 두면 넣지 않음), 수첩 글은 `NOTES`.
- 주소 끝에 `#debug` 를 붙이면 `window.__g` 로 상태를 볼 수 있습니다.

## 2D 미니게임판 (`/hq/`)

`hq/index.html` 은 `src/` 의 조각을 이어 붙인 결과물입니다. **`src/` 를 고친 뒤 `node src/build.mjs`**.
(`1_head.html` 스타일·뼈대, `2_core.js` 틀, `3_art.js` 그림, `4_hub.js` 본부·고르기 판, `5_play.js` 공통 틀, `6_games.js` 게임 다섯 가지, `9_boot.js` 시작)
