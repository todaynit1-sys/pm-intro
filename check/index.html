인증샷 확인 코드 확인

미션 완료 인증샷 아래에 찍힌 확인 코드(예: 7KXQ-4PMZ)가 진짜인지 확인합니다. 코드는 사진의 이름과 찍은 날짜로 계산되므로, 남의 사진을 가져오거나 사진의 이름·글자를 고치면 맞지 않습니다.

붙여 넣은 이름·연락처는 이 브라우저 안에서만 확인하고 어디로도 보내지 않아요.

응모 목록 한꺼번에 확인

구글폼 응답 시트에서 제목 줄까지 표를 통째로 복사해 붙여 넣으세요. 제목에 이름, 코드가 들어간 열을 찾아 확인하고, 전화·휴대폰·연락처 열이 있으면 같은 번호로 여러 번 낸 응모도 찾아요.

'결과 열 복사'를 누른 뒤 시트에서 비어 있는 열의 제목 줄 칸을 눌러 붙여 넣으면 줄마다 결과가 나란히 들어가요.

확인 범위와 읽어 두기
  • 코드 앞 4자리는 기기마다 처음 인증샷을 찍을 때 정해져요. 앞 4자리가 같은데 이름이 다르면 같은 기기에서 여러 번 낸 응모일 수 있어요 (드물게 우연히 겹칠 수도 있어요).
  • 이름의 띄어쓰기와 영문 대소문자는 따지지 않아요. 글자가 하나라도 다르면 코드가 맞지 않아요.
  • 코드는 게임 안에서 계산되므로, 게임 코드를 뜯어보는 사람까지 막지는 못해요. 경품이 큰 이벤트라면 추첨 뒤 당첨자의 게임 화면을 한 번 더 확인해 주세요.
